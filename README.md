# АвтоСмета

Калькулятор стоимости ремонта автомобиля с панелью администратора. Работает офлайн: один HTML-файл, без сервера и сторонних библиотек. Есть оболочка для Android (APK).

## Возможности
- Расчёт сметы: услуги с количеством, запчасти и материалы, скидка на работы, итог.
- Каталог из ~330 услуг в 22 категориях, поиск и фильтр по категориям.
- Выгрузка сметы: **CSV (Excel)**, **TXT**, **HTML** (открывается в браузере и печатается в PDF), копирование текстом, печать.
- Администратор (PIN, по умолчанию `1234`): добавление, правка и удаление услуг и цен, поиск по прайсу, резервная копия в виде текста, смена PIN.
- Данные хранятся в браузере или приложении (localStorage).

> PIN защищает только от случайных правок на устройстве. Это не серверная авторизация.

## Запуск в браузере
Откройте `docs/index.html` двойным щелчком или опубликуйте на **GitHub Pages**:
Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/docs`.

## Сборка APK
**В GitHub:** вкладка Actions → *Build APK* → Run workflow. Готовый `AvtoSmeta.apk` будет в разделе Artifacts. При пуше тега `v1.0.0` APK автоматически прикрепляется к Release.

**Локально:** Android Studio → File → Open → корень репозитория → Build → Build APK(s). Или в терминале (нужны JDK 17 и Android SDK):

    gradle wrapper --gradle-version 8.7
    ./gradlew assembleDebug

Файл: `app/build/outputs/apk/debug/app-debug.apk`.

Для публикации в Google Play нужен подписанный релиз с вашим ключом и актуальный `targetSdk`.

## Как менять прайс по умолчанию
Список услуг — массив `DEF` в `docs/index.html`. Пользовательские правки из панели администратора сохраняются отдельно и не затираются при обновлении.
